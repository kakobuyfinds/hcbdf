What to check before ordering

Save the exact listing and variant

Keep the CAFANS product link, seller listing if available, color, size and quote date in the same row of your shortlist. If you plan to use LitBuy, confirm that it accepts the source listing and displays the same variant before paying.

Compare like-for-like measurements

For clothing, measure a similar garment laid flat and compare chest width, body length and sleeve length in the same units. For shoes, check whether the seller’s chart uses foot length or insole length before comparing the figures.

Check warehouse QC photos

If your agent provides quality-control photos, compare the size label, color and visible construction with your saved variant. Ask for a close-up or a measurement if a detail is unclear. Check the exchange window before approving shipment.

Estimate your order total

Convert each amount to USD first. Enter the shipping quote for the packed parcel and any fees or import charges you expect to pay. Enter 0 for charges already included elsewhere.

LitBuy spreadsheet FAQ

What is a LitBuy spreadsheet?

It’s a way to organize product links, sizes, estimated prices and order notes when shopping through an agent. This page presents a selection from CAFANS in a searchable table.

Where do the product links go?

Each listing opens its CAFANS product page. Check that page and your agent’s order screen to confirm whether the item and selected variant are currently supported.

Why might two shipping quotes differ?

Quotes can vary by route, destination and the parcel’s billable weight. Ask whether the carrier uses actual or dimensional weight, then compare quotes using the same packed dimensions and included services.
